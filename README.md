# Ascent

## AI-Powered Student Growth & Career Intelligence Platform

Ascent is an AI-powered student success platform designed to track
student growth, skills, achievements, behavior, coding activity,
career progression, and domain interests.

## Technology Stack

### Frontend

- React
- Vite
- JavaScript
- Tailwind CSS
- Framer Motion
- React Router
- Axios
- Recharts

### Backend

- Python
- FastAPI
- Pydantic
- SQLAlchemy

### Database & Infrastructure

- PostgreSQL
- Redis
- Apache Kafka

### Machine Learning

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Joblib
